Current capabilities and remaining implementation work
DOCUMENTED FIXTURE PATHS

Structured artifacts and handoffs

  • Ingestion validates its demo manifest and emits five contract-aligned artifact types.
  • Research consumes upstream packages and emits a ResearchBrief and downstream handoff descriptor.
  • Media builds scene plans, placeholder media manifests, and run metadata.
  • Reusable GitHub workflows support transporting artifacts between stages.
LIMITATIONS TO KNOW

Acquisition, synthesis, and rendering

  • The ingestion demo does not retrieve raw content or perform AI enrichment. Its graph source references are empty.
  • ChunkSet is accepted for provenance, not used for research synthesis.
  • Full media rendering needs API keys and additional dependencies. No rendered-video result is claimed here.
  • Legacy pipelines and current fixture paths have separate dependencies and integration caveats.
Fixture compatibility and source-traceability work
WORK IN PROGRESS / COMPATIBILITY

Finding-field alignment

Research emits findings with claim and evidence_refs. The current Media consumer reads summary or text, plus citation_refs. Its handoff loader does not translate those fields.

A focused offline check with the committed ResearchBrief produced four finding scenes with empty citation lists and dictionary-shaped narration. The consumer's basic structural validator accepted the result.

Before claiming end-to-end provenance: align the finding fields and fixture packages, then verify citation preservation using the actual cross-repository outputs. This review did not modify the pipeline implementations.
